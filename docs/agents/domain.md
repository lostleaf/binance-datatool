# Domain documentation

This repository has one domain context: historical archive discovery, downloading, local storage,
and SHA256 verification.

Before exploring domain behavior, read the root [GLOSSARY.md](../../GLOSSARY.md) and any relevant
ADRs under `docs/adr/`, when present. Use the glossary's canonical terms in code, tests, issues,
and documentation. Surface conflicts with an existing ADR when proposing a change.

For terminology changes or architectural decisions, use the installed
[domain-modeling skill](../../.agents/skills/domain-modeling/SKILL.md). It owns glossary formats
and ADR criteria. Store qualifying decisions in `docs/adr/`; create that directory when the first
ADR is needed.
